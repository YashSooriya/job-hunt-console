JobHuntAI · Chrome extension

ChatGPT website bridge

This extension is a narrow visible-UI adapter. It receives an opaque dispatch id, asks the authenticated JobHuntAI MCP server for the server-approved workflow, and types only the fixed delivery instruction into the user’s bound ChatGPT Project conversation.

Permissions

Host access is limited to the configured JobHuntAI origin and chatgpt.com / chat.openai.com. The extension uses storage, tabs, alarms, narrowly scoped script injection for supported ChatGPT tabs, and downloads only to save a captured professional-profile JSON artifact. It does not request cookies, webRequest, debugger, history, clipboard access, or all-sites access.

Data boundaries

Only a short-lived device credential, the user-selected conversation URL, and dispatch metadata are stored locally. Applicant content is retrieved by the ChatGPT model through the authenticated MCP connection; the extension never receives it and never scrapes ChatGPT answers.

Memory and manual fallback

ChatGPT Memory and “use previous knowledge” are user-controlled in ChatGPT Settings → Personalization. JobHuntAI records only the user’s reminder/confirmation. When you confirm automatic setup, the extension can create the exact JobHuntAI Project through ChatGPT’s visible UI. If login, CAPTCHA, permission dialogs, a changed locale, an ambiguous Project control, or an ambiguous Send control appears, it pauses with a manual next step.
