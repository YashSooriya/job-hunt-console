Job Hunt · Chrome extension

ChatGPT website bridge

This extension is a narrow visible-UI adapter. It receives an opaque dispatch id, asks the authenticated Job Hunt MCP server for the server-approved workflow, and types only the fixed delivery instruction into the user’s bound ChatGPT Project conversation.

Permissions

Host access is limited to the configured Job Hunt origin and chatgpt.com / chat.openai.com. The extension uses storage, tabs, and alarms. It does not request cookies, webRequest, debugger, history, downloads, clipboard access, or all-sites access.

Data boundaries

Only a short-lived device credential, the user-selected conversation URL, and dispatch metadata are stored locally. Applicant content is retrieved by the ChatGPT model through the authenticated MCP connection; the extension never receives it and never scrapes ChatGPT answers.

Memory and manual fallback

ChatGPT Memory and “use previous knowledge” are user-controlled in ChatGPT Settings → Personalization. Job Hunt records only the user’s reminder/confirmation. If login, CAPTCHA, permission dialogs, a wrong Project, a changed locale, or an ambiguous Send control appears, the adapter pauses with a manual next step.

Extension version 0.1.0.
